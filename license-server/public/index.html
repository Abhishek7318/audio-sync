macOS Setup Guide

Downloading StoryStudio-1.0.0-arm64.dmg...

Step 1: Install

Open the downloaded .dmg file and drag Story Studio into your Applications folder.

⚠️ Step 2: If macOS shows "Damaged and can't be opened"

This is standard macOS Gatekeeper quarantine for apps downloaded from the browser. Run this 1-line command in Terminal to unlock it:

xattr -cr "/Applications/Story Studio.app"

💡 Open Terminal (press Cmd + Space, type Terminal), paste the command, and press Enter. Done!
